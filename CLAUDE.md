## Project Hub
Ideas are talked through on the Project Hub (https://claude.ai/artifact/4UFM9eMsCBJ4QYudXHnj1s, project `venus-os-mods`) and arrive here as **GitHub issues labelled `hub`**: each one is an agreed concept, ready to build.
- To build: list the open `hub` issues of this repo, build them one at a time following the rules above, reference the issue in the commit (`Fixes #n`), then close it with a short comment: what changed, how it was tested, the version.
- Unclear: ask in an issue comment and leave it open. Do not read or write the hub itself; closing the issue updates it.
